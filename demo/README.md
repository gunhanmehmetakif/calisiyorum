# Çalışıyorum demo
Node.js 25 ile çalışır; paket kurulumu gerekmez.
Proje kökünde `node demo/server.js` çalıştırın.
Tarayıcıda `http://localhost:5173` adresini açın.
Gemini kullanmak için `demo/.env.example` dosyasını `demo/.env` olarak kopyalayın.
`GEMINI_API_KEY` değerini yalnız `demo/.env` içine yazın.
İsterseniz `GEMINI_MODEL`, `GEMINI_FALLBACK_MODEL` ve `PORT` değerlerini değiştirin.
Anahtar yoksa üç soruluk yerel demo akışı çalışır.
AI isteği başarısız olursa arayüz otomatik olarak demo moduna geçer.
İlanlar, şirketler, eğitimler ve başvurular sunum amaçlı kurgusaldır.
